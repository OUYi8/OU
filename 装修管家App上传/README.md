# 装修管家 · 手机 App

装修进度 / 费用记账 / 验收留证 / 主材采购，一个 App 全搞定。数据全部存在手机本地，不上传服务器。

## 一、怎么拿到 APK（云端构建，你本机不用装任何东西）

整个流程在 GitHub 上跑，你的电脑只需要一个浏览器。

### 第 1 步：把代码传到 GitHub

1. 打开 <https://github.com/new>，新建一个仓库
   - 仓库名随便填，比如 `renovation-app`
   - 选 **Public**（免费额度更宽松，私有也行）
   - **不要**勾选 "Add a README"，直接点 **Create repository**

2. 在你电脑上打开这个文件夹，把代码传上去：
   ```
   E:\小龙虾缓存文件\2026-10-10-15-17-39\装修进度App
   ```

   如果你装了 GitHub Desktop：打开它 → Add local repository → 选这个文件夹 → Publish。

   如果你还没装 Git：**最省事的办法**是用网页上传。
   进入新建的仓库页面 → 找到 `uploading an existing file` → 把整个文件夹里的文件全拖进去
   （`node_modules` 文件夹很大，**不要上传**，等下第 2 步会自动安装）。

> 如果嫌文件多：我已经给你准备好了一个 `上传用的文件.zip`，解压后直接拖进 GitHub 就行。

### 第 2 步：等云端自动编译

传完代码后，GitHub 会**自动开始编译**（`.github/workflows/build-apk.yml` 已经配好）。

- 点仓库顶部的 **Actions** 标签 → 能看到 "构建 APK" 在跑
- 编译约需 **3-8 分钟**（第一次会下载 Android 环境，慢一些）

### 第 3 步：下载 APK 装到手机

编译成功后：

1. Actions → 点进那条绿色 ✔ 的记录
2. 滚到页面底部 **Artifacts** 区域
3. 点 **装修管家-debug.apk** 下载（会下载一个 zip，解压出里面的 apk）
4. 把 `app-debug.apk` 传到手机（微信文件传输助手 / QQ / 数据线都行）
5. 手机上点这个 apk 安装
   - 提示"未知来源"？设置里允许一下就行
6. 桌面出现 🏠 图标，打开即是 App

## 二、App 有哪些功能

### 🏠 总览
- 装修总进度环（自动统计所有阶段任务完成率）
- 已支出 / 剩余预算 / 预算执行率
- **⚠️ 需要马上处理**：逾期付款节点、到期的采购项
- 半包付款进度、四期节点
- 最近记账、14 天内要买的东西

### ⚡ 进度
7 个阶段：拆改 → 水电 → 防水 → 泥木 → 油漆 → 安装 → 竣工
- 每阶段可展开看子任务，勾选即完成，自动记录日期
- 每个任务可**拍照留证**（隐蔽工程必须拍照，出问题能追溯）
- 可自己加任务

### 💰 记账
- 记一笔：金额 / 分类 / 项目 / 日期 / 付给谁 / 备注 / 票据照片
- **自动识别增项**：备注里写"增项/补差/超预算"会自动标红并单独统计
- 分类预算条：超 100% 变红、超 90% 变黄
- 按月柱状图对比每月花销
- 按分类 / 按月份筛选

### 📦 采购（主材时间节点）
已按你家的清单预置 11 项，每项带计划采购日：
- 到期自动提醒「已逾期 N 天」
- 记录计划价 vs 实付价，自动算超支/省钱
- 分组：前期（封窗/瓷砖）→ 中期（吊顶/门/洁具）→ 后期（智能/软装/收尾）

### ✅ 验收（我的）
- 14 项量化验收标准，按 6 组分类（隐蔽/防水/泥木/油漆/安装/竣工）
- 每项都写清标准，比如「空鼓率 ≤5%」「接缝 ≤1mm」「水管打压保压30分钟」
- 勾选验收 + 拍照留证
- **半包付款台账**：勾选"已付"会自动在记账里生成对应支出，不会重复记
- **合同护栏清单**：7 条建议写进合同的关键条款

### ⚙️ 备份设置
- 改项目信息、总预算、各分类预算
- **导出备份**（含照片 / 不含照片）→ 换手机前务必先导出
- 从备份恢复
- 清空记账 / 恢复出厂数据

## 三、数据存在哪

- 全部存在手机浏览器的 **IndexedDB** 里
- **不上传任何服务器**，不需要注册账号
- 卸载 App 或清除数据会丢失 → **重要数据记得定期导出备份**

## 四、以后想改 App 怎么办

### 只改内容（推荐，最简单）

比如改了预算、加了新任务：
不用动代码，直接在 App 里点两下就改完了。

### 改界面/功能

1. 改 `www/` 里的文件（`index.html` / `css/app.css` / `js/*.js`）
2. 在电脑上跑一次同步：
   ```
   npm install
   npx cap sync android
   ```
3. 提交代码推送到 GitHub → Actions 自动重新编译 → 下载新 APK
4. 手机上装新版覆盖旧版，**数据不丢**（应用包名没变）

> 注意：覆盖安装时如果提示"应用未安装"，先卸载再装 —— 但这会丢数据，所以一定先导出备份。

### 改 App 图标

改 `make_icons.py` 里的颜色和图形，然后跑：
```
python make_icons.py
npx cap sync android
```

## 六、常见问题

**Q：编译失败了怎么办？**
A：点进失败的 Actions 记录，看红色报错。常见原因是代码有语法错误，可用
`node --check www/js/xxx.js` 检查。

**Q：APK 装不上提示签名冲突？**
A：说明之前装过同包名的不同版本。先卸载旧版再装（记得先导出备份）。

**Q：GitHub Actions 每月免费额度够用吗？**
A：免费账号每月 2000 分钟，编译一次约 3-5 分钟，个人用一年也用不完。

**Q：照片会不会把手机存满？**
A：照片会自动压到长边 1280px、JPEG 质量 70%，一张约 100-300KB。注意定期导出备份后清理。
